## SayWords 0.40.0

- **New name and icon.** SesCam is now SayWords. Your settings, history and permissions carry over.
- **Updates from inside the app.** SayWords checks for a new version once a day and notifies you; the update window downloads, verifies and installs it. You can also use "Güncellemeleri Denetle…" in the menu, or turn the daily check off in Ayarlar → Genel → Güncellemeler.
- Live dictation: editorial caption themes, a blue caption style, inline symbols and stickers, and a copy confirmation.
- AI editing can be switched on or off per recording.

If you installed the 0.30.2 beta, install this version by hand once (replace SesCam in Applications with SayWords); later versions update from inside the app.
